## [Deno 发布 celld：用 Rust 实现自托管 Durable Objects](https://github.com/denoland/celld) ⭐️ 7.0/10 · 相关 6/10

Deno 团队发布了 celld，这是一个开源守护进程，可以在你自己的基础设施上运行 Cloudflare Workers 和 Durable Objects。它用 Rust 编写，今天在 GitHub 上获得了 432 颗星。 该项目将 Cloudflare 的 Durable Objects 模型带到了自托管环境，相比使用 Cloudflare 的托管服务，成本可降低高达 88%。它可能使开发者无需绑定特定供应商即可构建有状态的分布式应用。 每个 cell 都由其自己的私有 SQLite 数据库支持，并持续以 LTX 格式复制到兼容 S3 的存储桶。技术栈包括 V8、SQLite、LTX 和 Tokio，采用 Apache-2.0 许可证。

github_trending · denoland · 8月9日 10:10

**背景**: Durable Objects 是有状态应用和分布式系统的构建块，在保持边缘性能的同时提供强一致性保证。Cloudflare 将其作为 Workers 平台的一部分引入，但此前仅作为托管服务提供。celld 旨在以自托管方式复制这一功能，让开发者拥有更多控制权并节省成本。

**对中国影响**: celld 可能使中国开发者和公司受益，因为它提供了 Cloudflare 托管 Durable Objects 的自托管替代方案，而后者在中国可能面临网络限制或数据主权问题。这与国内云原生和边缘计算发展的趋势相符。

**对我有什么用**: 作为电子工程师和硬件开发者，你可能会对 celld 感兴趣，因为它可用于构建需要状态协调的分布式物联网后端或边缘应用。然而，它主要是一个软件运行时，除非你将嵌入式设备与此类系统集成，否则它与硬件项目的直接关联有限。
