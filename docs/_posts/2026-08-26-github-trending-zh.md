## [omlx：面向 Apple Silicon 的 LLM 推理服务器，支持连续批处理与 SSD 缓存](https://github.com/jundot/omlx) ⭐️ 7.0/10 · 相关 4/10

omlx 是一个针对 Apple Silicon 优化的新型 LLM 推理服务器，具备连续批处理和 SSD 缓存功能，并可通过 macOS 菜单栏直接管理。本周其星标数增加超过 1400，反映出社区的高度关注。 该项目将连续批处理等生产级推理优化引入 Apple Silicon，使 Mac 上的本地 LLM 服务更快、更高效。它降低了开发者在本地运行大型模型的门槛，有望推动端侧 AI 应用的发展。 该服务器使用 Python 编写，集成了连续批处理以提高吞吐量，并通过 SSD 缓存减轻内存压力。它提供了 macOS 菜单栏界面，便于管理，但仅支持 Apple Silicon 硬件。

github_trending · jundot · 8月26日 01:35

**背景**: 连续批处理是 LLM 推理服务器中的一种技术，它会在槽位空闲时立即调度新请求，而不是等待整个批次完成，从而显著提高吞吐量。SSD 缓存将中间 KV 缓存存储在磁盘上，以减少内存占用，使得在有限内存下运行更大模型或更长上下文成为可能。这些优化在 vLLM 和 TGI 等框架中很常见，而 omlx 将其带到了 Apple 硬件上。

**对中国影响**: omlx 可能影响中国开发者和企业在 Apple Silicon 上的 AI 应用开发，提供本地推理选项，减少对云服务的依赖。它也可能启发国内 LLM 服务框架的类似优化，尤其是在边缘计算场景中。

**对我有什么用**: 作为电子工程师和硬件开发者，你可以研究 omlx 中连续批处理和 SSD 缓存的实现，这可能会为嵌入式或边缘 AI 项目带来类似的优化灵感。同时，它也是一个在 Apple Silicon 上本地运行 LLM 的实用工具，可用于原型开发 AI 驱动的硬件应用。
