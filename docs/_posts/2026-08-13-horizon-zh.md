### *（简报）* [Tailscale 追溯数据库损坏问题，发现 SQLite 中存在 16 年之久的 WAL 缺陷](https://tailscale.com/blog/sqlite-wal-reset-bug) ⭐️ 7.0/10 · 相关 4/10

Tailscale 工程团队将其控制平面长达六个月、间歇性出现的数据库损坏问题，追溯到 SQLite WAL（预写日志）模式检查点重置逻辑中一个存在 16 年之久的竞态条件。该公司还资助开发了一款开源的 SQLite VFS shim 调试工具，用于隔离该竞态并协助定位未来类似的 bug。 这个案例说明，即使是像 SQLite 这样久经考验、被广泛部署的软件，也可能隐藏着仅在生产环境中罕见时序条件下才会浮现的微妙并发缺陷。它同时也展现了企业定向资助开源工具的价值——一款能让竞态条件以确定性方式复现的 VFS shim，受益的不仅是 Tailscale，而是整个 SQLite 生态系统。 该 bug 是检查点操作与并发写入之间的数据竞争：如果写入恰好发生在最不利的瞬间，检查点进程会误以为已经复制了某些页面，而实际上并未复制，从而导致静默的数据丢失或损坏。Tailscale 在备份过程中激进且手动控制的检查点策略使他们特别容易触发该问题，而新开发的 VFS shim 正是为了以确定性方式复现这类线程交错执行场景。

<a id="item-3"></a>
### *（简报）* [阿里 Qwen 发布 Qwen3.8-2.4T MoE 模型，激活参数 95B](https://huggingface.co/Qwen/Qwen3.8-2.4T-A95B) ⭐️ 7.0/10 · 相关 7/10

阿里巴巴 Qwen 团队发布了 Qwen3.8-2.4T-A95B，这是一款混合专家（MoE）架构的大语言模型，总参数达 2.4 万亿，每个 token 激活 95B 参数。发布版本包含 FP8 和 1-bit 量化版本，其中 1-bit 版本体积为 397GB，完整的 BF16 版本则达到 4.9TB。 这是迄今为止最大的国产开源权重大模型之一，在规模上直接对标月之暗面 Kimi K3，将阿里推到了开源大模型竞赛的最前沿。激进的 1-bit 量化让接近旗舰级的性能可以被资金充裕的个人或小团队本地部署，与 DeepSeek 等国内厂商的竞争进一步白热化。 据称模型性能介于 Opus 4.8 与 Fable 5 之间。许可证允许内部使用或年收入低于 5000 万美元的机构免费使用，超出该门槛则受限制。值得注意的是，开源权重版本不包含视觉输入和 1M 上下文长度——这些功能仅在闭源的 Qwen3.8-Max 版本中提供。

<a id="item-4"></a>
### *（简报）* [Adam 优化器破坏梯度下降的隐式低秩偏置](https://www.reddit.com/r/MachineLearning/comments/1vmjb3p/the_loss_does_not_see_the_basis_but_adam_does_r/) ⭐️ 7.0/10 · 相关 2/10

一项新研究通过实验证明，正是 Adam 逐坐标二阶矩的各向异性破坏了梯度下降的隐式低秩偏置，并据此将 9 种优化器清晰地分成两类。作者还发现 Muon 在真正的低秩目标上表现精确，但随着谱尾能量的增加而退化，在约 4%尾能量处与 GD 发生交叉——这一发现调和了先前关于 Muon 谱简化偏置的相互矛盾结论。 隐式低秩偏置在理论上与深度线性网络和矩阵分解的泛化能力紧密相关；如果 Adam 系统性地破坏了它，那么在希望保留低秩结构的场景下该选哪种优化器就有了实际意义。Muon 的交叉现象也解释了为何先前研究在同一类问题上对同一优化器得出了截然相反的结论。 作者通过一个单参数族实验精确定位了机制——将 Adam 的分母从逐坐标平滑过渡到共享标量，恢复能力沿该轴单调改善。作者还修复了自己早期提出的优化器（恢复误差由 0.347 降至 0.220），方法是把逐坐标裁剪换成全局范数裁剪。理论仅覆盖无记忆规则，动量部分仍属经验性结论。43–44%的保留集误差降幅使用了仅基于训练集的学习率规则，实际上对 Adam 不利；若允许各方法自选最优学习率，差距会显著缩小（见附录 D.6）。
