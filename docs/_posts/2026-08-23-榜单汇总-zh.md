### [美加贸易谈判破裂，50%关税正式生效](https://www.axios.com/2026/08/22/us-canada-tariffs-trade-trump-carney) ⭐️ 8.0/10 · 相关 3/10

美加贸易谈判于上周五深夜破裂，约 200 亿美元加拿大商品被加征 50%关税，涵盖酒类、冰球器材、水泥和乳制品，自周六起生效。这是美国总统首次援引 1930 年《关税法》第 338 条加征关税，加拿大总理卡尼誓言将对等报复。 此次破裂标志着美国与其第二大贸易伙伴之间前所未有的关系断裂，也表明美国贸易政策正借助罕见法律工具变得更加强硬。叠加加拿大的对等报复威胁，这场争端有可能升级为覆盖整个北美地区的贸易战，并通过供应链产生全球性外溢影响。 1930 年《关税法》第 338 条授权总统对被认为歧视美国贸易的国家征收最高 50%的关税——该条款自法律颁布以来从未被启用过。能源、钾肥和关键矿产等加拿大重要出口商品被排除在新关税之外，受影响的 200 亿美元约占加拿大对美年出口总额的 5%。

rss · Axios (美洲) · 8月22日 15:58

**背景**: 1930 年《关税法》又名《斯穆特-霍利关税法》，由胡佛总统签署，对数千种进口商品征收高额关税，被普遍认为加剧了大萧条并引发全球报复性关税。其中第 338 条赋予总统对被认定歧视美国贸易的国家加征关税的权力——该条款沉寂了近一个世纪。特朗普此次援引该条款意义重大，因为它无需国会批准即可实施，且可叠加在包括 USMCA 框架下已有的关税之上。

**对中国影响**: 美加争端升级可能通过重塑北美供应链和贸易流向间接影响中国，例如让部分中国出口商品获得替代机会，或在被新关税扰乱的市场中寻找新空间。由于美加双边贸易额约为美中贸易额的两倍，持续的贸易中断可能改变中国参与行业的全球定价和采购格局。

**对我有什么用**: 这条新闻对电子工程师或硬件开发者的直接关联有限，但如果你的元器件、PCB 或原材料来自北美供应商，则需要关注可能的成本上涨和交期延误。半导体和关键矿产被排除在关税之外这一点，对使用加拿大原材料的硬件项目可能有一定意义。

### [omlx：面向 Apple Silicon 的 LLM 推理服务器，支持 SSD 缓存](https://github.com/jundot/omlx) ⭐️ 7.0/10 · 相关 4/10

开源项目 jundot/omlx 在一周内获得 1,597 颗 GitHub 星标，总星标数突破两万，达 1,723 个 fork。该项目是基于 Python 的 LLM 推理服务器，专为 Apple Silicon Mac 设计，通过持续批处理提升吞吐量，并利用 SSD 缓存机制加载超过统一内存容量的模型。同时提供 macOS 菜单栏图形界面来管理服务器。 它解决了一个 Mac 平台 AI 开发者的实际痛点：在 Apple Silicon 上运行大模型受限于统一内存容量。通过把权重卸载到 SSD，用户可以在消费级 Mac 上运行上百亿参数的模型而无需升级内存；持续批处理相比朴素批处理能带来 2–3 倍的吞吐量提升。菜单栏的交互设计也降低了非命令行用户本地自部署 LLM 的门槛。 项目使用 Python 编写，从命名推断很可能基于 Apple 的 MLX 推理框架作为后端。持续批处理在迭代级别调度新请求，而不是等整个批次跑完，这正是吞吐量提升的关键。SSD 缓存在统一内存与计算单元之间多了一层存储，以牺牲部分延迟为代价，换取加载超过 DRAM 容量模型的能力。

github_trending · jundot · 8月23日 01:06

**背景**: Apple Silicon 芯片（M1/M2/M3/M4）将 CPU、GPU 与统一内存架构（UMA）整合在一起，GPU 可以直接访问系统内存，速度比独立显卡方案更快，但总内存上限通常在 64–192 GB 之间。持续批处理（continuous batching）是 vLLM 和 Anyscale 推广的一种服务技术，它通过交错调度请求来保持 GPU 利用率，而不是等待长尾请求。SSD 卸载是一项成熟技术（DeepSpeed ZeRO-Inference 和 FlexGen 都在用），可以在显存不足时通过 NVMe 流式读取权重来运行超大模型。

**对中国影响**: 由于美国出口管制以及苹果在中国市场份额有限，Apple Silicon 在中国大陆属于小众平台，直接采用的用户不多。但 SSD 卸载技术本身与平台无关，可以为国内开源 LLM 服务项目（例如基于昇腾、寒武纪等国产硬件的项目）提供借鉴，因为这些平台同样面临显存/内存容量受限的问题。

**对我有什么用**: 对电子工程师或硬件开发者而言，omlx 是一个有参考价值的架构范例，展示了 Apple Silicon 中 SSD 与内存的带宽交互以及统一内存设计的影响。虽然它不是可复刻的板卡项目，但其中的 SSD 卸载思路可以启发基于 RISC-V 或其它 SoC、面临类似 DRAM 与存储权衡的边缘推理设备设计。

#### *（简报）* [用纯模拟电路打造盖革计数器](https://hackaday.com/2026/08/22/building-an-analog-geiger-counter/) ⭐️ 6.0/10 · 相关 6/10

**干啥的**：这是一个完全不使用微控制器的纯模拟盖革计数器方案，用一节 AA 电池驱动盖革-米勒管探测电离辐射，最终通过表头直接读出辐射强度。

**亮点**：
- 单节 AA 电池同时升压出 5V 和 400V，整机电源设计紧凑且经典。
- 信号链全部由分立模拟元件搭建，用 RC 低通滤波器把脉冲平均成连续电压，思路干净。
- 无 MCU、无 ADC、无 LCD，结构极简，调试和复刻门槛相对较低。
- 是一个把高压电源、运放、滤波、噪声抑制“打包练习”的典型模拟电子案例。

**我的判断**：整体来看，这是一个质量不错的教程型项目，适合作为模拟电子进阶练习。但因为盖革计数器本身偏小众，且没有给出完整 BOM 和 PCB，复刻时主要参考价值在设计思路和电源方案，而不是直接照搬做一台。如果你已经在玩模拟电路或者在准备一个辐射相关的教学 demo，可以参考其升压与信号调理部分；否则更建议先从网上现成的成熟 DIY 方案起步，本篇作为“补一点模拟味”的阅读材料即可。
