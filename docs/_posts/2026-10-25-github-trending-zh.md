## [Graphify 将代码库转换为可解释的本地知识图谱。](https://github.com/Graphify-Labs/graphify) ⭐️ 8.0/10 · 相关 8/10

Graphify 是一款 Python 工具，可将源代码、文档、SQL 模式、配置文件和 PDF 转换为可在本地查询的知识图谱。在统计当周，它新增 6868 个 GitHub 星标，累计达到 134492 个星标和 12837 次派生，并提供面向 Claude Code、Cursor、Codex 和 Gemini CLI 的 `/graphify` 技能。 Graphify 为 AI 编程代理提供了一种基于确定性、本地图谱的方案，可替代依赖嵌入的向量检索。开发者能够查询关系、追踪路径并检查每一条边，从而让代码和文档分析比相似度搜索更透明、更便于审计。 用户可运行 `graphify query`、`graphify path` 和 `graphify explain` 查询本地图谱；图谱默认位于 `graphify-out/` 目录，也可通过已连接的 MCP 服务器访问。工具能够输出 `graph.json` 和 `graph.html`，每条边会标为 `EXTRACTED`（提取）或 `INFERRED`（推断），并附带置信度元数据，便于区分推断关系。

github_trending · Graphify-Labs · 10月25日 01:48

**背景**: 抽象语法树通过明确的语法结构表示源代码，使解析器能够以确定性方式提取代码关系。知识图谱把实体表示为节点、把关系表示为边，因此既能进行精确查询，也能追踪关联路径。向量存储通常通过嵌入相似度检索内容，而 Graphify 试图绕过这一层，并为图谱中的每项关系提供解释。

**对中国影响**: 对中国开发者而言，本地且确定性的解析方式有潜力降低分析专有固件和内部文档的门槛，无需再引入托管式向量检索层。现有资料未显示与中国市场相关的采用情况、政策变化或供应链影响，因此其近期意义主要体现在开发工具，而非硬件制造。

**对我有什么用**: 对于从事固件开发的电子工程师，Graphify 可以把源代码与硬件文档、配置文件及 PDF 一起映射成图谱，让 AI 编程代理追踪依赖关系或解释设计要素。它适合作为可复现的本地分析工具，但现有资料没有表明它原生支持原理图、网络表、PCB 文件或特定 EDA 格式。
