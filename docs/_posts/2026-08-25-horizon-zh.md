<a id="item-2"></a>
### *（简报）* [seL4 微内核在 AArch64 上完成端到端安全证明](https://proofcraft.systems/news-2026/#2026-08-21) ⭐️ 7.0/10 · 相关 5/10

seL4 微内核针对 AArch64（ARM64）架构完成了端到端形式化安全证明，把严格的数学保障扩展到了主流 ARM 平台。这一里程碑建立在 seL4 此前已覆盖 x86 与 RISC-V 的形式化验证基础上，如今在 ARM 系统上也提供了机器可核查的机密性、完整性与可用性保证。 AArch64 在移动、嵌入式、汽车以及越来越多的服务器和云工作负载中占据主导地位，因此在它上面拥有完整验证的微内核，意味着 seL4 可以部署到更多对安全性和可靠性要求严苛的产品中。这也强化了 seL4 作为虚拟机管理程序底座的地位——它能够提供基于数学而非仅凭经验的安全论证。 该证明仍然不包括 MCS（混合关键性系统）扩展以及多核配置；和 seL4 的所有证明一样，它假定硬件、编译器以及启动代码是正确的，因此实际硅片上的侧信道攻击（缓存、时序等）并不在形式化保证范围之内。验证覆盖了从 C 实现到 ARM64 指令集二进制级别的对应关系。
