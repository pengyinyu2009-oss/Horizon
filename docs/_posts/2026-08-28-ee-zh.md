### *（简报）* [Yumo Roulette：基于 ESP32 的六联旋转桌面装置](https://www.reddit.com/r/ElectricalEngineering/comments/1vzxtuj/i_built_6x_rotating_displays_a_desk_gadget/) ⭐️ 6.0/10 · 相关 8/10

**干啥的**: Yumo Roulette 是一个开源桌面装置，把 6 块 240×240 的圆形 TFT 屏装在一个可旋转的轮盘上，由 ESP32-WROOM 驱动，能同时显示 SD 卡照片轮播、YouTube/TikTok 频道数据、加密货币行情、实时天气和室内温湿度，并支持电容触摸一键旋转。

**亮点**:
- 倒置电机方案非常巧妙：把整个旋转框架装在直流电机的外壳上，转轴反过来插入电钻夹头固定，实现了"无可见中轴、看起来悬浮旋转"的效果，绕开了滑环这一昂贵部件
- 单 ESP32 同时驱动 6 块共享 SPI 总线的 GC9A01 圆形屏，并用 TJpg_Decoder 在本地直接解 SD 卡里的 JPEG，省掉了图像预处理步骤
- Wi-Fi 凭证通过 ESP32 自带的 Captive Portal 配置，没有硬编码；同时拉取 YouTube Data API v3、RapidAPI 上的 TikTok 数据和 OpenWeatherMap 天气，多数据源整合在一个固件里
- 物料清单非常亲民：ESP32、DRV8833、N20 电机、TTP223 触摸、AHT10 温湿度、NeoPixel、SD 模块，全是创客圈常见元件

**我的判断**: 这是个值得复刻的好项目，尤其适合已经玩过 ESP32+OLED、想要尝试多屏复用和旋转机械结构的进阶玩家。代码和硬件方案都已经在 GitHub 开源，文档看起来也比较完整，复刻门槛主要在机械部分——钻夹头定位、电机的装配精度和配重都需要耐心调，而不是单纯堆元件。从项目质量、社区分享诚意和性价比来看都很不错，但比较适合愿意花时间手工调机械的玩家，对纯软件方向或完全没接触过嵌入式的人来说学习曲线会偏陡。
