### [中国科学家将氢燃料电池功率输出提升四倍](https://www.scmp.com/news/china/science/article/3367077/chinese-scientists-boost-hydrogen-fuel-cell-power-fourfold-new-design?utm_source=rss_feed) ⭐️ 8.0/10 · 相关 3/10

北京理工大学的研究团队在《Science》期刊发表论文，报道了一种新设计，将质子交换膜燃料电池（PEMFC）的功率输出提升了四倍。 这一突破有望大幅拓展氢燃料电池的应用场景，从道路车辆延伸至太空领域，加速清洁氢能的普及。功率密度提升四倍意味着在同等输出下电堆体积和重量可以大幅缩小，这对车载和航天应用都至关重要。 该研究针对的是目前氢动力车辆常用的质子交换膜燃料电池（PEMFC）。文章暗示涉及设计层面的创新（可能与膜电极组件或流场结构相关），完整技术细节需查阅《Science》原文。对于一种已经商业化的燃料电池技术，功率提升四倍是相当显著的飞跃，而非渐进式的改进。

rss · South China Morning Post (亚太) · 9月10日 18:00

**背景**: 氢燃料电池通过氢与氧之间的氧化还原反应，将化学能直接转化为电能，唯一排放物是水。PEMFC 属于低温燃料电池，常用于车辆；固体氧化物燃料电池（SOFC）则在高温（600–850°C）下工作，可以使用更广泛的燃料。北京理工大学是位于北京海淀的公立研究型大学，属于中国 985 工程和双一流建设高校，其前身可追溯至 1940 年创办的延安自然科学院。

**对中国影响**: 这一突破巩固了中国在氢能技术领域的领先地位，支撑国家清洁能源转型战略，可能为中国整车企业与航天项目在国内外部署下一代燃料电池系统提供有力支撑。

**对我有什么用**: 这并非直接面向开源硬件或嵌入式开发的新闻，但关注清洁能源电力系统的硬件开发者可以研究其公开的膜电极与流场设计原理，用于燃料电池电堆的原型设计，或跟进此类高功率密度电堆所需的功率电子与电池管理系统（BMS）设计。

JustVugg/colibri 是一个用纯 C 语言编写、零外部依赖的轻量级 MoE（混合专家）大模型推理引擎，通过把专家权重从磁盘流式读入内存，让前沿 MoE 模型可以在普通消费级硬件上运行。该项目在 GitHub 已累计获得 27,475 星，今日新增 98 星，社区关注度较高。 像 Mixtral、DeepSeek-V3 这类前沿 MoE 大模型因为总参数量高达数千亿且分散在大量专家网络中，通常需要多卡服务器才能运行；而 colibri 的磁盘流式方案让单台工作站只需把当前激活的专家常驻内存即可处理这些模型。这显著降低了个体开发者、研究人员和小团队体验开源前沿 MoE 架构的硬件门槛。 该引擎完全用 C 实现，没有任何外部依赖，采用按需分页方式从磁盘读取专家权重，而非把整个模型都放进内存或显存，思路接近 mmap 这类内存映射流式读取。27,475 星和 3,011 fork 表明项目相当成熟并被广泛派生，但其核心创新集中在工程优化层面，并非 MoE 推理架构本身的基础性突破。

github_trending · JustVugg · 9月11日 01:28

**背景**: Mixture-of-Experts（MoE，混合专家）是一种神经网络架构，由门控网络把每个输入 token 路由到少量专门的“专家”子网络，使模型总参数量极大但每个 token 实际只激活一小部分参数。前沿 MoE 大模型往往包含数百个专家，总参数量达数十万亿，远超任何单卡消费级 GPU 的显存容量。按需加载和内存映射流式读取等技术——把磁盘视作内存的慢速一层、按需把权重分页读入——已经成为应对显存受限硬件的常见方案。

**对中国影响**: 中国的开源 MoE 生态（DeepSeek-V3、Qwen-MoE、Hunyuan-MoE 等）已经产出世界领先的前沿 MoE 模型，而 colibri 这种纯 C 零依赖推理引擎让中国开发者更容易在本地已有硬件上部署这些模型，无需依赖 NVIDIA CUDA 体系或大型 GPU 集群。这对难以获取顶级显卡资源的国内独立开发者、高校实验室以及边缘 AI 创业公司都比较友好。

**对我有什么用**: 对电子工程师或硬件开发者来说，colibri 的间接价值在于展示了如何通过巧妙的存储分层设计（把磁盘当作内存/显存的扩展层）把前沿 AI 塞进普通硬件，这种思路在设计 Flash 或 PSRAM 紧张的嵌入式系统时同样值得借鉴。如果你做 Linux SBC 或 RISC-V 板卡，可以尝试在不带独立显卡的开发板上跑一些小型 MoE 模型，搭建本地化的设备端助手。

#### *（简报）* [Hackaday 开源声学无人机检测项目](https://hackaday.com/2026/09/10/open-source-acoustic-drone-detection/) ⭐️ 6.0/10 · 相关 7/10

**干啥的**: Hackaday 上发布的一个开源项目，教你用麦克风阵列采集无人机桨叶和电机的特征声音，再通过 DSP 和机器学习进行检测与分类，本质上是一套低成本的被动式反无人机感知方案。

**亮点**:
- 完整开源，从硬件（麦克风阵列、嵌入式开发板）到软件（信号处理、分类模型）都有实现思路，方便复刻和改造
- 采用被动声学方案，不发射任何射频信号，因此合法部署门槛低，也避开了 RF 探测对预编程自主飞行和光纤 tether 无人机失效的盲区
- 涉及频谱图、小波变换、时频分析等 DSP 手段，以及 CNN/RNN/CRNN 等深度学习分类器，是嵌入式+ML 的典型练手组合
- 与反无人机这一热点军事/安防话题结合，工程实用价值高，可直接套用到机场、电站、活动现场的低空周界监测

**我的判断**: 作为一个可复刻项目质量不错，文档完整性依赖原 Hackaday 文章，需要读者自行补全 BOM 和代码；复刻门槛中等——硬件端只要有 ESP32/Raspberry Pi 加几只麦克风即可跑起来，但要做高精度就需要在麦克风选型、阵列几何和数据集上投入精力。适合做嵌入式/DSP/边缘 AI 的工程师，以及对反无人机、安防监测感兴趣的学生和创客。如果你想做严肃的反无人机产品，建议把它当成原型验证和算法起点，而不是直接可用的成品。
