## [ESP-SDR 在 ESP32 上实现发射功能](https://hackaday.com/2026/10/13/esp-sdr-can-now-transmit/) ⭐️ 7.0/10 · 相关 8/10

**干啥的**: ESP-SDR 是基于 ESP32 内置 2.4 GHz 射频收发器，把原本只服务于 Wi-Fi/BLE 的硬件直接当成软件定义无线电来用的开源项目，最新进展是把接收能力补齐为收发双向。

**亮点**:
- 利用片上 I2S 外设 + DMA 直接拿到射频基带的原始采样，绕过 Wi-Fi/BLE MAC 层，是把消费级芯片压榨到协议栈之下的典型案例
- 硬件门槛极低，理论上任何带 2.4 GHz 射频的 ESP32 变体都能跑，复刻成本几乎就是一块开发板的价格
- 上一周刚出现两个几乎同时的独立破解，社区热情和复现活跃度高
- 从纯接收扩展到发射，让自制 OOK/FSK 信标、信号发生器、2.4 GHz 协议模糊测试都成为可能

**我的判断**: 非常值得动手复刻和学习。文档和源码公开、所需硬件只是一块常见的 ESP32 开发板，对于想了解 SDR 信号链、射频前端和 DMA 数据通路的人来说，是一个成本几乎为零的优秀练手项目；对硬件开发者而言也提供了一个低成本的协议研究与安全实验平台。适合嵌入式/射频入门者、物联网安全爱好者以及任何想在工作台上多一台 2.4 GHz 信号源的工程师。唯一需要留意的是当地无线电发射管理规定——能发射不等于可以随便发射。

rss · Hackaday · 10月13日 20:00

**背景**: 软件定义无线电（SDR）是用运行在嵌入式或通用处理器上的软件，去替代传统上由模拟硬件实现的混频器、滤波器、调制解调器等部件，射频前端加 ADC/DAC 负责把天线和处理器连接起来。ESP32 各型号内部都集成了一颗原本只服务于 Wi-Fi 和蓝牙的 2.4 GHz 射频收发器。社区近期的工作展示了如何绕过片上 MAC 层，通过 DMA 把原始 IQ 采样经 I2S 引脚引出来，从而把 ESP32 变成一台粗糙的 SDR 接收机。把同一条通路延伸到发射端，便可主动产生 OOK/FSK 等调制信号、做信号源或在 2.4 GHz 频段上进行协议模糊测试。

**对中国影响**: ESP32 由总部位于上海的乐鑫科技设计，国内开发者和创客社区对这款芯片接受度极高，因此这一破解会迅速在国内创客与物联网安全圈流传，让中国爱好者以几乎零成本获得一台可玩性 SDR 平台。

**对我有什么用**: 对电子工程师来说，这是一个极易复刻的周末项目：仅需一块 3–5 美元的 ESP32 开发板加上已发布的固件，就能获得一台能收能发的 2.4 GHz SDR，非常适合教学、物联网协议模糊测试以及自制信号源，省下一台 USRP 或 HackRF 的钱。

## [FPGA 编年史：在 Tang Nano 20K 上准备探针调试](https://hackaday.com/2026/10/13/the-fpga-chronicles-ready-to-probe/) ⭐️ 5.0/10 · 相关 7/10

**干啥的**: 这篇 Hackaday 文章是「FPGA Chronicles」系列的最新一篇，作者基于 Sipeed Tang Nano 20K 这块约 25 美元的开发板，对 GOWIN 官方 EDA 工具链与 Yosys + nextpnr 开源工具链进行了实操对比，并准备进入下一阶段的片内信号探针调试。

**亮点**:
- 用同一块 Tang Nano 20K 同时跑 GOWIN 商业工具与开源工具，给出第一手对比
- 涉及的资源较少：20736 LUT4、64Mbit QSPI Flash，但足够软核跑 RISC-V
- 顺带引出 GOWIN 自带的 GAO（Gowin Analysis Oscilloscope）片内逻辑分析仪，为下一篇埋伏笔
- 选题契合 FPGA 学习者关心的「去厂商锁定」与「低成本入门」两大痛点

**我的判断**: 这篇文章本身并不是突破性技术，更像是一篇实战型连载笔记，但放在 FPGA 入门的语境下，它值得复现：复刻门槛低（开发板 25 美元、工具免费），适合想从「跑官方 demo」跨到「自己搭开源工具链」的电子工程师与学生读者。文档完整度上依赖系列前几期，单篇独立阅读价值一般。如果你正在评估要不要入坑 Tang Nano 20K 或想试一下 Gowin 开源流程，这篇是一个不错的索引。

rss · Hackaday · 10月13日 14:02

**背景**: FPGA（现场可编程门阵列）是一种出厂后仍可反复烧写逻辑的芯片，让工程师无需流片 ASIC 就能验证自定义硬件。传统 FPGA 设计流程依赖厂商专属的 EDA 工具完成综合、布局布线与比特流生成，爱好者长期被锁定在单一厂商生态里。Tang Nano 20K 之所以流行，是因为 GOWIN 是目前少数拥有可用开源工具链（Yosys + nextpnr）的厂商之一，与 Lattice iCE40、ECP5 阵营类似。所谓「探针」，是指利用 FPGA 自带的片内逻辑分析仪功能（比如此处提到的 GOWIN GAO，即 Gowin Analysis Oscilloscope）来观察芯片内部实时信号。

**对中国影响**: GOWIN（高云半导体）是本土 FPGA 厂商，Tang Nano 20K 由深圳 Sipeed 推出，这篇文章进一步让全球爱好者社区看到了完全由国内厂商构成的 FPGA 硬件加工具链生态。围绕 GW2A 的开源工具链也降低了中国学生和创客的入门门槛。

**对我有什么用**: 对电子工程师或硬件开发者来说，如果你在考虑用 Tang Nano 20K 加开源工具链替代厂商闭源流程，这个系列是一份实用的入门参考。它同样有助于你搭建一套基于 Yosys/nextpnr、面向 Gowin 器件的开源开发环境，从而不再被 Windows 专属工具束缚。

**入选理由**: 文章涉及 FPGA 开发（Tang Nano 20K）以及开源 FPGA 工具链，与读者关注的 EDA、嵌入式、开源硬件方向高度契合，工具链对比对工程师有实用参考价值。
