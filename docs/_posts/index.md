## 🛠 数据流

- **采集**：7 天滚动，12 个一级信源 + 6 个二级聚合 + GitHub Trending（daily/weekly/monthly）
- **筛选**：每榜单约 50 条候选 → 客观分前 10 + 主观分 top 3 精选
- **分析**：双评分 + 五栏目（入选理由 / 背景 / 对中国影响 / 对沈阳影响 / 对我影响）
- **GitHub 热榜**：额外评估「对这个项目有什么用」——点名可插入/可借鉴的 cw 模块，给可复刻 vs 可集成结论；五星推荐 + 🔥 必看标记
- **汇总**：每榜单 1 段分析 + 跨榜单关联
- **发布**：VPS 08:17 BJT 主任务；10:30 / 21:17 幂等补偿；GitHub Actions 仅手动备用
