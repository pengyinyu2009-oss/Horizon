## [Deepity 宣称 MNIST 预测编码基准领先](https://www.reddit.com/r/MachineLearning/comments/1xg6sqa/deepity_a_handtuned_ccuda_predictive_coding/) ⭐️ 6.0/10 · 相关 7/10

作者发布了 Deepity 0.1.0a3，这是一款采用 MIT 许可证的预测编码库，包含 C++20 核心、手写的 AVX2/AVX-512 SIMD 内核、BLAS 矩阵乘法、Python 绑定，以及仍在开发中的 CUDA 后端。在一台配备 i7-12700H 笔记本处理器的电脑上进行的同配置 MNIST 实验中，它报告了 98.21% 的准确率和 487.5 秒的耗时；基于 JAX 的 jpc 为 97.55% 和 531.4 秒，NGC-Learn 为 98.00% 和 1,707.7 秒。 Deepity 将手写 SIMD、BLAS 和 CUDA 优化带入预测编码实现，使其成为一个少见的偏系统工程实践。若结果能够复现，该库可为关注底层性能的开发者提供一份紧凑的参考实现；不过，单台笔记本上的作者自测不足以证明它在所有场景都具备普遍优势。 基准使用 784-512-512-10 的 sigmoid 网络、20 次稳定迭代、250 的批量大小以及 AdamW 优化器训练 100 个周期；其中 PyTorch 结果仅供参考，因为反向传播每个批次只前向计算一次，而预测编码需要 20 次稳定迭代。作者估算端到端运行约为 675 GFLOP/s，内核基准约为 690 GFLOP/s，但 0.1.0a3 仍是阿尔法版本且由一人维护；CUDA 大规模训练还在优化，卷积使用 im2col 加 cuBLAS 而非 cuDNN，目前也未公布 CUDA 与 CPU 的性能对比。

reddit · r/MachineLearning · /u/Important-Home4431 · 10月26日 19:34

**背景**: 预测编码不同于反向传播：每一层都会维护一个局部状态，并将其与来自上层的预测进行比较。训练过程先进入稳定阶段，由各层反复减少局部预测误差，再根据本层误差更新权重，因此无需保存反向计算图，也不需要其他层的转置权重。SLEEF 是支持 AVX2 和 AVX-512 的人工向量化数学函数库，而 NGC-Learn 是用于构建和分析预测编码及神经生物学系统的 Python 框架。

**对我有什么用**: 对电子工程师或硬件开发者而言，Deepity 提供了一个不依赖完整机器学习框架、可用于实验 SIMD、BLAS 与 CUDA 集成的具体项目。其源代码、原始日志和 Python 软件包降低了复现 MNIST 基准的门槛，也可以参与其尚未完成的 CUDA 性能优化。

**入选理由**: 项目直接涉及读者关注的 AI 开发工具链与底层性能优化，开放的 C++/CUDA 源码也便于试验和复现；不过其与开源硬件、EDA、嵌入式及鸿蒙开发的关联较弱。
