# 第 23 讲 · 反激钳位与漏感能量

上讲自测答案：1. 驱动地若与功率地共线，主回路 di/dt 在共段电感上感应出电压，直接叠加进栅极回路——轻则波形畸变，重则超过阈值误开通造成串通。2. 最有效位置是紧贴开关对（上下管中点附近）就近换流：高频电流只走最小环，远处的电容根本来不及参与，母线大电容只负责低频补能。

核心原理：反激变压器耦合不到 100%，漏感 Llk 像「挂在原边的独储能罐」：

· 关断瞬间：励磁能量走副边输出，但漏感能量无处可去，电流强行给 MOSFET 结电容充电 → Vds 尖峰，不加钳位直接超耐压。
· RCD 钳位：D + C + R 把尖峰能量吃掉变成电阻热。钳位电压 Vclamp 通常取反射电压 Vor 的 1.5~2 倍：设低了损耗大、设高了尖峰高，是折中艺术。
· 有源钳位：用一个小 MOS + 小电容把漏感能量回收并实现软开关，效率高但控制复杂，Ga_N 快充与 OBC 辅源常见。
· 准谐振（QR）：等漏感与结电容谐振到谷底再开通，即 65W 复刻的 MK2697G 工作方式。

公式：Vds_peak ≈ Vin_max + Vclamp；Vclamp = Vor + ΔV；R = Vclamp²/P_rcd，C ≥ I_pk·ton/(Vripple)；漏感能量 E = ½·Llk·I_pk² 全部进钳位。

算例：65W 复刻：Vor ≈ 100V，取 Vclamp = 150V，Llk = 10µH、I_pk = 1.5A，E = 11.25µJ ×65kHz ≈ 0.73W —— 一颗 1W 贴片电阻刚好，散热铜皮要给足。

与 OBC 的联系：CLLC/DAB 里漏感被「转正」为谐振电感，是设计参数而非事故；但辅源（给控制板供电的小反激）仍要老老实实做 RCD。
