# 第 27 讲 · 安规距离与耐压测试

上讲自测答案：1. 并联：每颗器件各自「结→壳→TIM→共用散热器」，到散热器之前是两条独立热阻，共用段（散热器→环境）才串联；等效按「各自的 Rth(j-h) + 共用 Rth(h-a)·总功率份额」算，共用段上两颗的功耗叠加。2. 硅脂本体导热率只有 ~1 W/mK，远低于金属；它只是用来填平微观空隙（空气 0.03）的，涂厚了低导热层变成主热阻——正确量是「薄到刚好润湿」。

核心原理：安规距离是「物理绝缘」，耐压测试是「验证绝缘」，两件事互相印证：

· 电气间隙（clearance）：空气中直线距离，防击穿（雷击/瞬态过压）。一次侧对二次侧 220V 系统 ≥6.4mm（加强绝缘）。
· 爬电距离（creepage）：沿绝缘表面走的距离，防长期污秽漏电起痕。同等级 ≥6.4~8mm，开槽可以「绕远路」增加爬电而不占面积。
· 绝缘等级：基本（一层）、附加（第二层）、双重/加强（等效两层）——充电器外壳到一次侧必须是加强绝缘。
· 耐压（HIPOT）：一次-二次加 3000VAC/1min 无击穿、漏流 <几 mA；输入对外壳 1250VDC 等。产线全检，型式试验加湿度预处理。
· Y 电容漏流：人体可触及输出端时泄漏电流限 0.25mA 级，直接限制 Y 电容总量 → 与 EMI 滤波打架，设计要两头算。

公式：无（本讲是规范应用）；记住爬电 ≥ 间隙（同等级下），因为表面路径更易积污。

算例：65W 充电器：变压器初次级间三层胶带 + 挡墙（margin tape）保证 6mm 以上；PCB 一次-二次分区间开槽，槽宽 3mm、爬电路径 >6.4mm；Y 电容合计 <2.2nF 控制漏流。耐压测试一次对二次 3000VAC 时注意：把 IC 的信号隔离（光耦）也算进受试路径，光耦的绝缘等级必须同栏过关。

与 OBC 的联系：OBC 输入是交流桩（基本绝缘）但输出 400V 直流对车身底盘是双重绝缘+绝缘监测（IMD）双保险；HIPOT 电压等级按 2×系统电压+1000V 取，预充继电器的触点间隙也要按此校核。
