# 第 16 讲 · EMI：车规 CISPR 25

上讲自测答案：ADC 触发点放在 PWM 计数器周期点/零点——离开关沿最远、电流处于平均意义点，采样抖动影响最小。增量式 PI 不配反计算 → 积分器 windup，退出饱和时严重超调甚至失控。

核心原理：车规 EMI 标准是 CISPR 25（保护车载接收机），比桌面电源的 CISPR 32/23 严得多：传导 150 kHz-108 MHz（峰值/平均值双限值线，Class 5 最严）、辐射 150 kHz-1 GHz。共模路径：绕组→散热器/机壳寄生电容→机壳→电池包 PE。车规 Y 电容总量受漏电流限制，不能靠堆 Y 电容；手段=屏蔽绕组+共模磁芯+桥臂对称性；有源 EMI 滤波（AEF）开始上车。

与 OBC 的联系：OBC 的 EMI 是整车 EMC 的一部分（部件级+整车级两级测试）；桌面电源对标 CISPR 32 Class B，限值松得多。做 OBC 要把 EMI 当系统问题：功率级对称性、磁件屏蔽绕组、两级 Y 电容分配，从拓扑选型阶段就要考虑。
