# 第 30 讲 · OBC 系统整合：从框图到量产（收官）

上讲自测答案：1. 反激变压器是「储能源件」（原边储能、关断后释放，按 Lp 与 I_pk 设计）；LLC/正激家族是「传能变压器」（原边同时向副边传功率，按 ΔB 损耗与漏感设计）——一个看饱和，一个看损耗与谐振参数。2. 400V > 市电峰值 311V，保证整个工频周期 Boost 都能升压工作；380V 在 305V 市电上限附近余量不足，过零附近控制会饱和。

核心原理：把 1-29 讲组装成一台 6.6kW OBC：

· 系统分解：AC 榫头 → EMI（CISPR 25）→ 图腾柱 PFC（SiC，400V 母线）→ 母线电容（纹波电流与 hold-up 时间双约束）→ CLLC 或 DAB（400V↔250~450V 电池）→ 同步整流 → 接触器/预充 → 电池。控制板：DSP 双核（PFC 环 + DC/DC 环 + CAN 通信 + 诊断）。
· 控制自由度分配：PFC 占空比管电流波形、CLLC 频率/ DAB 移相管输出、电池侧接触器管时序——每个自由度一个闭环，互不抢方向盘。
· 开机时序：低压上电 → 自检（ADC/驱动/通信回环）→ 预充（限流给母线电容充电）→ 闭合主接触器 → 使能 PFC → 使能 DC/DC → CAN 握手（GB/T 27930 与桩/VCU 协商电流曲线）→ 功率爬升。
· 保护矩阵：过流（硬件比较器逐脉冲关断）、过压（两级：降功率 + 接触器）、过温（降额曲线）、绝缘监测（IMD 持续查漏阻）、HVIL（物理互锁）——每条都要有「不依赖软件」的最后一道闸。
· 效率地图与热联合仿真：标定阶段扫全工况，效率峰设计在常用区；水冷板流量按峰值损耗点定。

公式：6.6kW/94% 效率 → 总损耗 ≈ 420W 分布：PFC 160W + CLLC/DAB 200W + 辅源/采样/驱动 60W；水冷板 ΔT=15°C 需流量 ≈ P/(c·ρ·ΔT) ≈ 420/(4180×1000×15)×60 ≈ 0.4 L/min 起步，取 2~3 倍裕量。

算例：验收清单（节选）：满载效率 ≥93.5%（250V/450V 两端点各测）、PF≥0.99、THD<5%、输出纹波 <1% 、开机过冲 <5%、CISPR 25 Class 5 传导辐射全过、满载 45°C 环境连续 4h 无降额、-40°C 冷启动、抛负载/反接后功能正常——每一条都是 1-29 讲的一个考点。

与 OBC 的联系：本讲就是 OBC。收官不是终点：800V 平台（SiC 主场、DAB 优势放大）、双向 V2G 商用化、集成电驱三合一（OBC+DCDC+MCU）是下一步方向。

自测题：1. 为什么预充接触器不能省？2. 全部 30 讲回望：哪三讲的知识在开机时序里同时被用到？

（答案：1. 母线电容直接短接电池会瞬间大电流打火，预充电阻先限流充到 90%+ 再闭合主接触器。2. 开放题——示例：第 5 讲（采样时序）、第 9 讲（软启动 PI）、第 19 讲（HVIL/接触器安全）——能自圆其说即通过。）
