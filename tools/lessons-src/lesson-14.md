# 第 14 讲 · DAB 与多移相控制

上讲自测答案：双向功率流要求副边主动可控——副边开关管当有源桥用，二极管只做死区续流。增益规律：fsw>fr 增益<1（降压），fsw<fr 感性区增益>1（升压），两侧全范围 ZVS。

核心原理：DAB = 全桥-变压器-全桥 + 外置漏感/谐振电感，8 管全控。单移相（SPS）唯一自由度 d=φ/π，传输功率 P = n·V1·V2·d(1−d)/(2·fs·Lk)，d=0.5 时最大；缺点是轻载回流功率大。双移相（DPS）/三重移相（TPS）增加桥内移相自由度，在满足功率指令约束下最小化回流功率与电流应力——800 V 宽电压双向 OBC 的热点方案。

公式：P = n·V1·V2·d(1−d) / (2·fs·Lk)，d = φ/π。

算例：400 V→400 V、Lk=30 µH、fs=100 kHz、n=1：d=0.5 时 P ≈ 400×400×0.25 / (2×100k×30µ) ≈ 6.7 kW，正好覆盖 7 kW 级 OBC；电池掉到 300 V 时 SPS 打满也传不到额定 → 必须放宽 Lk 或上多移相+调频。

与 OBC 的联系：800 V 平台电池 250-450 V 宽范围变化，CLLC 调频范围吃紧 → DAB+多移相是 800 V 双向 OBC 的主流后级之一。取舍：CLLC 额定点效率高，DAB 调压范围宽。

自测题：1) 由 SPS 公式说明 d=0.5 传输功率最大（P∝d(1−d)）。2) 内移相为什么能减少回流功率？（桥内 0 电平改变电感电流与端口电压的相位关系）
