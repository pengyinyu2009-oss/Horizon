# 第 20 讲 · 结业：从桌面电源到 OBC 的路线

上讲自测答案：OBC 的安全状态 = 继电器断开、隔离高压；粘连检测 = 继电器两端主动脉冲检测触点状态，防止触点粘死导致电池无法与 OBC 隔离（维修/碰撞后危险）。

核心原理：三阶段技能地图。
· 基础：伏秒平衡 → 拓扑（Buck/Boost/反激）→ 器件（电感/电容/MOSFET/GaN/SiC）→ 环路与补偿 → 磁/EMI/热。
· 桌面电源：输入级 → PFC → AHB/LLC → 同步整流 → PD3.1 → 保护/EMI/调试。
· OBC：图腾柱 PFC → CLLC/DAB → 数字控制（C2000）→ 磁集成/水冷 → 车规与功能安全/EMI。

公式：PFC（功率因数校正）→ DCX（固定匝比谐振）→ 双向后级 = OBC 主链。

90 天路线：第 1 月，桌面电源关键级复刻（PFC 电感绕制 + AHB 变压器绕制）；第 2 月，CLLC/DAB 仿真（LTspice/PSIM）+ C2000 数字控制半实物；第 3 月，写一份 6.6 kW OBC 方案书：指标分解（效率 96%+、密度 3 kW/L、车规）→ 拓扑论证 → 关键磁件设计。
