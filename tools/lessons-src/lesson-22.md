# 第 22 讲 · 功率 PCB 布局三大环路

上讲自测答案：1. 三查 = 查器件定额（耐压/电流/功耗对峰值含振铃留裕量）、查回路完整性（每个网络有源有宿、地有汇合点）、查保护独立路径（过流/过压/过温不依赖单一软件路径）。2. 软件过流有采样-判断-动作延迟（µs 级），短路电流上升只需几百 ns，等 MCU 反应器件已炸；必须硬件比较器或熔丝直接拉关断。

核心原理：布局决定一台电源的「隐藏参数」——寄生电感。所有高频大电流问题几乎都是环路面积 × di/dt：

· 功率环路：开关管 + 变压器/电感 + 母线电容围成的换流回路，面积每平方厘米都在制造 V = L·di/dt 尖峰与 EMI。第一铁律：功率环路面积最小（DAB/图腾柱每相的桥臂中点要紧贴）。
· 驱动环路：驱动 IC → 栅阻 → 栅极 → 源极 → 驱动地。这个环大了，di/dt 感应电压直接顶开栅极。SiC 必须用开尔文源极 + 就地去耦。
· 采样/信号地：模拟小信号地与功率地单点相连，接点选母线电容的安静端；绝对禁止信号地穿过功率回路。

公式：趋肤深度 δ=√(2ρ/ωμ)，100kHz 铜约 0.21mm；1oz 铜皮载流经验值（10°C 温升）1oz 约 1A/mil×0.5 系数，即 20mil 线宽约 10A，功率走线宁宽勿窄、过孔并联。

算例：65W GaN 反激：一次侧功率环（输入电容-桥-变压器原边）控制在 2cm² 内；RCD 钳位紧贴变压器漏感端；输出同步整流环同理。二次大面积铺铜兼做散热。

与 OBC 的联系：6.6kW 图腾柱 PFC 的 EMI 与效率一半在布局里；每相桥臂用独立陶瓷电容组就近换流；母线电容的 ESL 分层排布是 800V 平台的关键细节。
