# 第 29 讲 · 65W→300W：桌面电源升级路线

上讲自测答案：1. 冷态时 MOSFET Rds(on) 低温更低（正温度系数器件）、磁芯损耗低温略低、二极管 VF 低温更高——综合下来冷机导通与磁损都偏小，效率虚高；热稳态才是真实交付值。2. 会看到高频开关噪声尖峰叠加（几十 MHz 的振铃），那是测量带宽问题不是真实纹波；规格里的纹波定义本身就带 20MHz 限制条件。

核心原理：从 65W 到 300W 不是「按比例放大」，是拓扑换代：

· 为什么 65W 方案到不了 300W：单级反激在 300W 下原边峰值电流大、变压器与 EMI 滤波器体积爆炸、效率顶到 88% 就上不去。
· 两级架构登场：PFC 级（升 400V 母线、矫正功率因数）+ DC/DC 级（400V→输出）。65W 单级 vs 300W 两级，是功率等级的质变线。
· DC/DC 三条路：LLC（效率最高、调频控制、单向）、AHB（非对称半桥，动态母线宽范围、适合 PD 快充多档）、移相全桥（300W+ 到 kW 级通用）。你的 300W 目标推荐 PFC+AHB 或 PFC+LLC。
· 沿用与重建：PFC 的图腾柱知识（第 7/8 讲）、环路（第 25 讲）、磁设计（第 4/6 讲）全部复用；变压器从「储能源件」变「传能变压器」（反激→正激家族），设计思路要换脑子。
· 数字化时机：300W 桌面电源值得上数字控制（STM32G4/C2000），PD 协议、多档输出、CC/CV 切换都是软件活——正好接上第 5/9/15 讲。

公式：两级效率 η = η_PFC × η_DC；300W 目标分配：PFC 98% × DC 96% ≈ 94.1% 整机。

算例：300W 损耗预算表：PFC 级 6W（SiC 图腾柱 4W + 电感磁芯 1.2W + 其他 0.8W）；DC/DC 级 12W（变压器 2.5W + 原边开关 3.5W + SR 2W + 驱动/辅助 1.5W + 磁/容 2.5W）；合计 18W → 94.3%，余量 1.5% 留给高温退化。风冷散热器 Rth 需 ≤1.8°C/W。

与 OBC 的联系：300W 桌面电源就是 6.6kW OBC 的「缩比模型」——同样 PFC+隔离 DC/DC 两级、同样的控制问题、同样的 EMI/热链条。把 300W 做明白，OBC 只剩功率器件选型与水冷/车规两章新知识。
