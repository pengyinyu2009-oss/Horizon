# 第 15 讲 · 数字控制实现

上讲自测答案：P = n·V1·V2·d(1−d)/(2·fs·Lk)，d=0.5 最大；内移相在桥臂中点电压产生 0 电平段，削减电感电流与端口电压的相位差（回流功率分量），同功率下电流应力更小。

核心原理：增量式 PI——u[k] = u[k−1] + Kp·(e[k]−e[k−1]) + Ki·Te·e[k]；输出是占空比/移相角增量，天然配输出限幅；抗饱和用反计算（anti-windup，饱和时按 (u_sat−u)·Ka 回灌积分器）。执行时序：ADC 触发与 PWM 周期点同步（ePWM SOC），中断里 读ADC→PI→写比较寄存器 一拍完成。OBC 控制频率=开关频率（100-300 kHz），C2000 主频 100-200 MHz，每拍预算 1-2 µs。先浮点仿真定参，量产再考虑定点。

公式：u[k] = u[k−1] + Kp·(e[k]−e[k−1]) + Ki·Te·e[k]

算例：fs=100 kHz 数字环，Te=10 µs；电流环带宽取 fs/20 = 5 kHz、相位裕度 50°。PI 先在 PSIM/Simulink 整定，上机先用保守参数（带宽减半）再逐步推。ADC 触发点设在 PWM 计数器周期点（避开开关沿噪声），电流采样取开关周期平均值。

与 OBC 的联系：OBC 数字电源核心技能：C2000（F2837x/F28P65x）的 ePWM+ADC+CLA。图腾柱 PFC 双闭环、CLLC 调频、DAB 移相全部在一个中断里完成。桌面电源用 STM32/GD32 同理，思想一致。
