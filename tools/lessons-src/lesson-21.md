# 第 21 讲 · 原理图评审：从「看懂」到「挑错」

上讲自测答案：框图从左到右：AC 输入 → EMI 滤波器 → 图腾柱 PFC（快管 SiC 桥臂 + 慢管工频桥臂）→ 母线电容（400V）→ CLLC 或 DAB（高频变压器隔离）→ 同步整流 → 电池接口（含继电器预充、绝缘监测 IMD、HVIL 互锁）。控制自由度：PFC 占空比、CLLC 开关频率 / DAB 移相角，外加电池侧接触器时序。能独立画对，第 1-20 讲的主干就通了。

核心原理：评审不是逐个器件重看一遍，而是按「网口」分组查问题：

· 网络类：每个网络都有源和宿吗？悬空引脚、未连接的 PWM/ADC 引脚、地网络分了数字地/功率地却没有单点汇合点，都是高频事故。
· 功率类：电流主回路上每个器件的耐压/电流/功耗定额留裕量了吗？MOSFET 看 Vds 峰值（含振铃）而不只是母线电压。
· 驱动类：栅极电阻、关断回路、负压/钳位是否齐全；驱动 IC 供电的去耦电容就近了吗。
· 采样类：采样分压比、滤波、跟随器带宽、ADC 基准；电流采样的位置（电感前/后）与量程。
· 保护类：过流（硬件比较器还是只靠软件）、过压、过温各有一条独立路径吗；软启动时序。

公式：无（本讲是方法论）。

算例：拿 65W GaN 复刻原理图过清单：发现输出侧 IP2723T 的 CC1/CC2 下拉电阻与母板不一致（第 10 讲提过的坑）、变压器同名端画反会导致同步整流出力相反、缓冲电容的耐压按 2 倍尖峰复核。三处都是「能仿真通过、一上电就翻车」的典型。

与 OBC 的联系：车规评审更严——每条保护要求有 FMEDA 对应项、每个器件有 AEC-Q 证号栏位、每页有版本与签核栏。评审记录本身就是交付物。
