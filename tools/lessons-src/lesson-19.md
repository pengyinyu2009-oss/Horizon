# 第 19 讲 · 车规与功能安全

上讲自测答案：Tj 预算余量是给老化和暂态工况的——寿命末期内阻上漂、高温老化工况叠加，不留余量 = 寿命末期超温。高频化是第一杠杆：磁件储能体积 ∝ 1/f 量级，频率×4 磁件小 4 倍量级，是 1.5→4 kW/L 的主引擎。

核心原理：车规三件套。器件认证 AEC-Q101（分立器件）/Q200（无源）；功能安全 ISO 26262（ASIL A-D，OBC 常见 ASIL B-C，安全状态 = 继电器断开隔离高压）；高压安全：HVIL 高压互锁探测回路断开、维修插销、继电器粘连检测（两端主动脉冲检测触点状态，防粘死导致电池无法隔离）。ISO 21434 网络安全对 OBC 是新增要求；GB 38031 电池安全提一句。

与 OBC 的联系：桌面电源没有这三件套，OBC 的 BOM/流程/测试都按车规重做：器件选型看 AEC-Q 认证、控制代码按 ISO 26262 流程开发（需求→设计→单元验证全程追溯）、整机测振动/温度循环/IP 防护/耐久。
