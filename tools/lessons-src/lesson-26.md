# 第 26 讲 · 热设计与散热器选型

上讲自测答案：1. PM≈45° 阶跃响应有 2~3 次明显振铃、稳态略过冲；PM≈60° 几乎无振铃、单调收敛——量产取 60° 是给器件容差和老化留的保险。2. 误差放大器输出端是高阻抗节点，注入电流会被放大器输出阻抗与补偿网络分压，测量到的相位失真；分压电阻处两端都朝低阻抗看，注入信号干净。

核心原理：热设计 = 把损耗「搬运」到环境的能力设计，一切围绕热阻链：

· 先列损耗清单：每颗器件的导通+开关+驱动损耗（前面各讲的公式在这里汇总），没有清单的热设计都是猜。
· 链路：结→壳（Rth(j-c)，手册给）→TIM→散热器（Rth(h-a)）→环境。串联叠加，瓶颈永远在最粗的一段。
· 散热器选型三问：自然对流还是强迫风冷（差 5~10 倍）？翅片方向与气流是否顺路？安装孔布局会不会让 TIM 干涸？
· TIM 的坑：硅脂太厚比不用还糟（厚度主导热阻）；相变片需要在首次升温后「活化」；螺丝顺序影响接触压力分布。
· 结温校核：Tj = Ta + ΣP·Rth ≤ 目标（SiC 常按 125°C 留 25°C 裕量到 150°C 上限）。

公式：Tj = Ta + P·(Rth(j-c) + Rth(c-h) + Rth(h-a))；自然对流散热器经验 Rth ≈ 50/√A（°C/W，A 为有效表面积 cm² 量级估算）。

算例：65W 复刻总损耗约 5.5W（92% 效率）：变压器 1.2W + SR 0.4W + 原 MOS 1.1W + EMI/其他 2.8W。灌封外壳自然对流整体 Rth 约 8°C/W → 温升 44°C，夏天 35°C 室温到 79°C 外壳——摸着烫手但器件结温还在 110°C 内，合规。换 94% 效率方案损耗降一半，温升立减 22°C。

与 OBC 的联系：6.6kW OBC 损耗约 300W 量级，风冷到顶也就 3kW/L；水冷板把这 300W 直接交给电池冷却回路，是功率密度上 4kW/L 的前提——第 18 讲的链路在这里落地成选型计算。
