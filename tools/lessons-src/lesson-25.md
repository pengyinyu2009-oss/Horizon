# 第 25 讲 · 环路测量：注入法与伯德图

上讲自测答案：1. 关断延后 = 电流已经反向还导通，倒灌能量并与原边开关共同导通形成瞬间短路，炸管；提前关只是走一小段体二极管，多损耗不致命——同步整流的时序错误要「宁早勿晚」。2. 轻载 DCM 电流断续，SR 若保持导通，输出电感/谐振电流会把能量反向抽回原边，输出电压被拉低、空载炸机；关 SR 回二极管模式，天然单向。

核心原理：仿真给环路，实测定生死。频率响应分析仪（FRA）注入小信号扰动，直接量出开环传递函数：

· 注入点：选在反馈分压电阻上（上臂或下臂），这里两端都是低阻抗方向、注入不破坏电路工作。注入电阻典型 10~100Ω，注入变压器隔离。
· 扫频：从 10Hz 到穿越频率的 5~10 倍，每点等幅稳态后采样，注意信噪比——输出纹波会淹没太小的注入，注入太大又进入非线性。
· 判读三数：穿越频率 fx（一般取开关频率的 1/10~1/20）、相位裕度 PM（≥45°，推荐 60°）、增益裕度 GM（≥10dB 保险）。
· 数字环路：注入法同样适用，但要考虑 1~1.5Ts 的采样延迟，它吃掉相位、压低可用带宽——数字电源的 fx 通常比模拟版更低。

公式：PM = 180° + φ(fx)；负载阶跃电压跌落 ΔV ≈ ΔIo/(2π·fx·Cout) —— 想压跌落就提穿越频率，但相位裕度在后面盯着你。

算例：一台 400V 母线电源 fx=2kHz、PM=35°：阶跃响应必振铃；把 PI 的 Kp 降 30% 后 fx=1.2kHz、PM=58°，振铃消失但跌落变大——带宽与稳定性的经典交易。65W 复刻的 TL431+光耦环路实测同法，光耦的 CTR 老化会让 PM 逐年变差，这是「用了两年开始啸叫」的常见根因。

与 OBC 的联系：OBC 的 PFC 电压环/电流环、CLLC 环路都要在样机阶段实测伯德图；量产标定把不同母线电压/负载下的环路参数做成表格。
