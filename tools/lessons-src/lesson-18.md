# 第 18 讲 · 水冷与功率密度

上讲自测答案：Lr = 一次/二次绕组间漏感，Lm = 励磁电感，全部由一个磁件的绕组结构决定；PCB 绕组尺寸一致 → 漏感可重复 → 集成磁件良率有保障。

核心原理：OBC 功率密度竞赛已到 3-6 kW/L（三代产品 1.5→2.5→4 kW/L）。手段：SiC 高频化（fsw 100→500 kHz）→ 磁件小一个量级；平面变压器+PCB 绕组（低 profile、可直贴水冷板）；水冷板与功率级直贴（模块级热阻 0.5-2 K/W）。结温预算 Tj = T_coolant + ΣP·Rth，冷液 −40~65 ℃、环温 −40~85 ℃。

公式：Tj = T_coolant + ΣP·Rth

算例：3.3 kW 水冷 CLLC：损耗 60 W（效率 98.2%），水冷板热阻 0.8 K/W，冷液 65 ℃ 极限工况：Tj ≈ 65 + 60×0.8 = 113 ℃，远低于 SiC 的 175 ℃——但已用掉预算的 80%，说明密度再往上必须先降损耗或降热阻。

与 OBC 的联系：桌面电源自然对流/强迫风冷 → OBC 水冷：散热设计从「选散热器」变成「设计冷板+流道+泵流量」。结温预算要给老化和暂态留余量，降损耗永远是第一优先级。
